# Codificador de Música

Visualizador web audio-reactivo inspirado en `custom-gian-spotify`.

## Qué hace

- Fondo negro espacial con estrellas, nebulosas, planetas y cometas animados.
- Reproductor para cargar archivos de audio locales desde el navegador.
- Modo demo con osciladores Web Audio si no hay archivo cargado.
- Rectángulo/placa blanca central con visualización tipo cimática.
- Análisis FFT en tiempo real para transformar frecuencias en patrones cromáticos saturados y complementarios.

## Desarrollo

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
